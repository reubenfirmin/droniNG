# Application settings import and export

Application settings describe desktop preferences, gadget/workspace layouts and plugin settings. They are different from [controller UAV settings](OnlineHelp:-UAV-Settings-import-export).

In the application settings import/export panel, choose the categories to include:

- General settings
- Gadget/workspace configurations
- Plugin settings

Export writes an XML file. Import reads the selected categories from an XML file into the current application profile. Restart the application after import so the restored configuration is used consistently.

Use the reset action only when you intend to remove the application's saved settings. Keep an export if you need to recover the current layout or preferences.

Replaces the [dRonin application-settings help stub](https://github.com/d-ronin/dRonin/wiki/OnlineHelp:-Import-Export).
