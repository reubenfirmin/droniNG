This is the droniNG UAVTalk API.  With these modules, it is possible to
communicate with droniNG flight controllers and interpret log files and
settings partitions.

The optional graphical log viewer requires Python 3.10 or newer, PyQt6 and
pyqtgraph 0.14. Install the ``all`` extra to include these dependencies. It uses
Qt 6 exclusively; the desktop GCS has its own pinned Qt 6.12.0 runtime.
